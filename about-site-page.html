About Health Buddy

Health Buddy is a healthcare information website created to help users explore health tips, disease information, latest health news, and basic symptom checking in a simple and user-friendly way.

Project Objectives

  • To provide basic healthcare information through a responsive website.
  • To help users search diseases and medical conditions using an API.
  • To display health tips using JSON and JavaScript.
  • To practise client-side scripting using HTML, CSS, JavaScript, AJAX, and JSON.

Website Features

Symptom Checker

Allows users to select symptoms and view possible related conditions.

Disease Search

Uses an external API to retrieve disease and medical condition data.

Health Tips

Displays health tips from JSON with search, filter, and read more features.

Health News

Provides health-related news and awareness content for users.

Technologies Used

HTML CSS JavaScript AJAX JSON Fetch API GitHub

API, AJAX & JSON Usage

The Disease Search page uses JavaScript Fetch API to retrieve data from an external medical API. The Health Tips page uses JSON data to store and display health tip content dynamically. These features allow the website to update content without reloading the entire page.

Accessibility & Responsiveness

Health Buddy includes responsive design for mobile devices, a hamburger navigation menu, readable content layout, back-to-top button, and font size controls to improve accessibility for users.
